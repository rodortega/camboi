Start calls on the loop
When a site opens your camera, go straight to the loop instead of live. You decide when to be seen.
Wait for a clean frame
Never go live — or start recording — while the camera is dark or still adjusting.
Auto-stop recordings
Off means a recording runs until you press Stop. Longer clips loop more naturally but are held in memory until you stop them.

Worth knowing

  • This only affects calls running inside Chrome. The native Zoom, Teams and FaceTime apps cannot see it.
  • Your camera light stays on while looping — the real feed keeps running so going live is instant.
  • Nothing is uploaded. Clips live in this browser profile's local storage.
  • Audio is never touched, recorded or routed.
  • Changing where CamBoi runs takes effect the next time a page asks for the camera.
